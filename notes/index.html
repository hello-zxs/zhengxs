The habit

These are the notes I keep while working. A note is not a paper: it is allowed to be partial, to show a calculation that failed, to end with a question. What it is not allowed to do is hide the assumptions.

Each entry states its model, gives the parameters, and links to the code or the paper it belongs to. If a figure is computed in the browser, the same computation is described in the text. If you find a mistake, the email link at the bottom is the fastest way to fix it.
