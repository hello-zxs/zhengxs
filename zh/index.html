物理学硕士生 · 研究光如何被几何塑造
变换光学、测地透镜与量子光学

简介

我是 Zheng Xiangsheng（郑翔升），厦门大学马来西亚分校物理系本科毕业生，2026 年秋起在西安大略大学（Western University）攻读物理硕士，现居加拿大安大略省伦敦市。

我的研究围绕一个简单的问题：几何如何决定光的路径？在变换光学中，坐标变换可以写进材料的介电常数与磁导率；在测地透镜中，一个梯度折射率介质可以等价为一张弯曲的曲面。数学上这是同一个想法的两个方向，实验上它们各自有完全不同的困难。

研究方向

  • 变换光学：坐标变换与等效介质、共形映射、隐身与超表面设计。
  • 测地透镜：Morse、Luneburg、Eaton 剖面的度规等价、闭合条件与射线追踪。
  • 量子光学：单光子干涉、路径信息与干涉可见度、量子擦除。

代表工作

本科毕业论文 Ray tracing and equivalent geodesic lenses for the Morse lens（2026）证明：共形 Morse 透镜是 Cornbleet 一般族的 (A = B, C = 1) 子类，参数对应为 a = −1/B；并构造了 Luneburg、Eaton 以及中间 Morse 剖面的等效测地曲面，用射线追踪验证了度规等价。论文全文与 PDF 可在本站阅读。

这个网站

本站收录论文、研究笔记和可交互的几何光学图。页面用原生 HTML、CSS 与 JavaScript 手写，没有框架、没有统计脚本；字体自托管；托管于 GitHub Pages。研究页上的 Luneburg 射线、隐身网格与单光子干涉图都在浏览器中实时计算。

它不是一个孤立的网站：Index 在此，Lab 在 qmentropy.com，Record 在 zhengxiangsheng.com。三个站点共享同一套字体、角色色与导航坞，各有不同的读者与时间尺度。
